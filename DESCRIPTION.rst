Ciphwren DAV is a CalDAV and CardDAV front-end for Etebase (EteSync 2.0) accounts.

This package provides a local CalDAV and CardDAV server that proxies requests
to an Etebase server for use with desktop CalDAV and CardDAV clients.

This is essentially a compatibility layer between Etebase and DAV clients.
It's an independent fork of `etesync-dav <https://github.com/etesync/etesync-dav>`_.
